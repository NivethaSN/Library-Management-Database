# Library Management Database System

## Project Description
This project is a Library Management Database System developed using MySQL. It manages books, users, and book issue and return transactions.

## Technologies Used
- MySQL 8.0
- MySQL Workbench
- SQL

## Database Tables
1. **Books** – Stores book details and available copies.
2. **Users** – Stores library user information.
3. **Transactions** – Stores book issue and return details.

## Features
- Add, update, delete, and view books.
- Manage library users.
- Issue books and return books.
- Track available book copies.
- View transaction history.
- Generate library summary reports.

## SQL Concepts Used
- DDL and DML commands
- Primary Key and Foreign Key
- Constraints
- Joins
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Views
- Stored Procedures
- Indexes
- COMMIT and ROLLBACK

## How to Execute
1. Open MySQL Workbench.
2. Connect to MySQL Server.
3. Open `library_management.sql`.
4. Execute the SQL script.
